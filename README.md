# Hi, I'm Carsten 👋

Solo builder from Germany. I help small businesses — mostly in the trades — put AI to work, and I build and run the systems myself, in production, every day.

Most of it is built together with Claude Code: apps vibe-coded from idea to production, and autonomous agents that do their work in the background without anyone clicking a button.

## What's running

- **Operations dashboard for a pipe & sewer services company** *(private)* — one place for jobs, email, calendar, invoices, phone calls and inspection videos, with an AI assistant on top. FastAPI · React · TypeScript.
- **AAIOS** *(private)* — my AI operating system: a social planner publishing to Instagram, Facebook, LinkedIn, TikTok and YouTube, and **Javis**, a voice-enabled AI coworker with tool use, long-term memory, a browser agent and an approve-before-write gate. Exposed to other AIs via an MCP server.
- **Autonomous background agents** — about a dozen scheduled jobs: incoming invoices from the mailbox into accounting, review requests a few days after a job, emergency calls turned into leads and alerts, competitor and website monitoring, lead sync and weekly AI reports.
- **AI-Tresor** — local approval vault for AI agents (Go · Wails · macOS/Windows). Agents ask for access, a human approves; the secret never appears in chat. → [ai-tresor.com](https://ai-tresor.com)
- **[blueprint](https://github.com/motodigitalguru-beep/blueprint)** — concept builder for Claude Code: a module blueprint with interface contracts before any code is written.
- **[ableton-mcp-extended](https://github.com/motodigitalguru-beep/ableton-mcp-extended)** — Ableton Live via MCP: device parameters, LUFS and masking analysis, automatic masking fixes.

## How I work

Claude Code as a small dev team: parallel sessions for frontend and backend, written specs and handoffs between them, and a human approval step before anything writes to the outside world.
